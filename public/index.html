About ExamPro

A professionally built Advanced Online Examination System — designed as a BCA Final Year Project to demonstrate full-stack web development skills using only HTML, CSS, and JavaScript.

🎯 Our Mission

Built to Make Exams Smarter

ExamPro was conceived to solve a real problem — traditional paper-based exams are slow, error-prone, and hard to manage. We built a complete digital alternative that runs in your browser and is powered by a Node.js + Express + MongoDB backend.

From creating exams to tracking student results, every feature is designed with both educators and students in mind. The system stores everything in a MongoDB database behind a Node.js + Express API, so your data is safe and available from any device.

🛠️ How It's Built

Technical Architecture

🗄️

MongoDB Storage

All users, exams, and results are stored in MongoDB through a secure Node.js + Express API. Data persists across sessions and devices.

🎨

Pure CSS Design

Every animation, layout, and visual effect is hand-crafted in CSS — no frameworks like Bootstrap or Tailwind. Fully custom design system.

⚡

Vanilla JavaScript

All logic — from authentication to exam grading — is written in plain JavaScript. No jQuery, no React. Single HTML file, zero dependencies.
