📖 JSON File kaise use karein?

Step 1 — Questions Generate karo
Left side pe topic likhke AI se generate karo, ya manually add karo.
Step 2 — JSON Download karo
"Download JSON" button click karo — questions.json file save hogi.
Step 3 — Main App mein Import karo
ExamPro → Admin Panel → Create Exam → "Import from JSON" button click karo → downloaded file select karo → questions auto-load ho jayenge!
📋 JSON File Format
Yeh file ExamPro ka standard format follow karti hai:
  • title — Exam ka naam
  • subject — Subject
  • duration — Minutes mein
  • passingScore — Pass percentage
  • questions[] — Question array
  • questions[].text — Question text
  • questions[].options[] — 3-5 options
  • questions[].correct — 0-based correct index
⚠️ Important Notes
  • Correct answer index 0 se start hota hai (pehla option = 0)
  • Minimum 2 options, maximum 6 options per question
  • JSON file edit karke manually bhi questions likh sakte ho
  • Ek JSON file mein multiple exams rakh sakte ho
